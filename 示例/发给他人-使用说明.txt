三校区低空货运航路展示 —— 一键打开说明
========================================

【本机打开】
1. 双击「打开航路展示.bat」
2. 浏览器会自动打开 http://localhost:8080/
3. 点击「最快路线」或「安全路线」查看三维航道
4. 用完后关闭黑色命令行窗口即可

【发给别人时请打包】
请把整个「三校区货运航路规划」文件夹打包发送（至少包含 web 目录与本 bat）。
对方电脑需要已安装 Python 3（安装时勾选 Add to PATH）。

【若打不开】
- 提示找不到 Python：先安装 Python 再双击 bat
- 端口被占用：关闭其它占用 8080 的程序，或改 bat 里的端口号
- 地图空白/要 Key：检查 web\config.js 中的高德 Web 端 Key 与安全密钥

【操作提示】
- 右键拖动可旋转地图，Ctrl+拖动调俯仰，滚轮放大
- 红线：南→北 210 m；蓝线：北→南 160 m
